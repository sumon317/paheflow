First-time setup

cookie needed

animepahe.pw is protected by Cloudflare. The GUI needs the cf_clearance cookie and the matching User-Agent from the same browser session.

  1. 1
    Open the site and pass the Cloudflare check. Use animepahe.pw in the browser you normally use.
  2. 2
    Copy the cf_clearance value. DevTools → Application → Cookies → animepahe.pw → copy cf_clearance. The cookie is HttpOnly, so JavaScript cannot read it. Then .
  3. 3
    Match the User-Agent, save, and test. Click Use this browser's User-Agent, then Save configuration and Test connection.
